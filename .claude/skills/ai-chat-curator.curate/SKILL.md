# 후보 정리 — 묶고, 빼고, 고르게 고른다

이 단계가 실행 결과의 구성을 정한다. 여기서 한 도구나 한 유형에 쏠리면 뒤 단계가 고칠 수 없으므로, 고르는 기준을 숫자로 확인하며 진행한다.

## 1. 읽기

- 실행 폴더의 `00_main_options.json`(기간·개수·초점), `00_main_feedback.md`(반응 요약)
- `01_collector_{a,b,c,d}.json` — 없거나 빈 파일은 `notes`에 적는다
- 게시 기록: `python -I .claude/skills/ai-chat-curator/scripts/curator.py posted-list`로 읽는다

## 2. 원출처 기준으로 묶기

같은 사건·기능·이야기를 다룬 항목은 후보 하나로 합친다.
- 대표 링크(`primary`) 우선순위: 공식 발표 > 최초 보도 언론 > 실무자 글 > 커뮤니티 글
- 항목의 `original_source_url`이 같으면 같은 소식이다. 다르게 보여도 같은 기능·같은 발표면 합친다
- 커뮤니티에서 시작된 이야기는 대표 링크가 공식이 되더라도 `community_origin: true`를 유지한다 — 교차 확인 단계가 반드시 다루게 하기 위해서다
- 합친 항목 ID를 `from_items`에 남긴다

## 3. 빼기

`dropped`에 이유와 함께 남긴다.
- **중복**: posted.md에 같은 링크가 있거나, 링크는 달라도 같은 내용(같은 기능 발표, 같은 팁)을 이미 제안·게시했다. 다만 같은 기능의 **새 변경**(예: 출시 → 한국 출시, 요금 인하)은 새 소식으로 본다
- **광고**: 대표 링크가 유료 강의·제휴·판매 글이다. 같은 내용의 다른 출처가 있으면 그것을 대표로 바꾸고 남긴다
- **업무 무관**: 개발자 API 세부, 투자·주가, 연예성 이슈처럼 직장인 업무와 연결이 약하다
- **안전 위반 팁**: 회사 기밀·개인정보를 넣으라는 전제가 깔린 팁. 단, 그 위험을 알리는 「주의할 점」으로 바꿀 수 있으면 유형을 바꿔 남긴다

## 4. 유형·관련도 정하기

- 유형은 수집자의 `type_guess`를 참고해 다시 정한다. 같은 재료라도 방 분위기에 맞는 유형을 고른다(예: 요금 변경 소식 → "여러분 팀은 어떤 요금제 쓰세요?" 질문거리로 바꿀 수도 있다)
- 업무 관련도
  - **상**: 많은 직장인의 일상 업무(문서·메일·회의·엑셀·보고)에 바로 영향이 있거나 바로 써먹을 수 있다
  - **중**: 특정 직무나 일부 사용자에게 영향이 있다
  - **하**: 알아 두면 좋지만 당장 업무가 바뀌지는 않는다
- `needs_verification`: 유형이 소식·팩트체크이거나 `community_origin`이 참이면 반드시 참. 업무 팁이라도 "~가 된다/안 된다" 같은 기능 주장이 있으면 참

## 5. 고르기

후보 10개 내외(최대 12)를 고르고, 그중 문안 추천(`recommend: true`)을 옵션 개수만큼 표시한다(기본 3~5, 검증에서 빠질 것을 대비해 최대값보다 1~2개 더 표시해도 된다).

구성 기준(옵션에 초점이 없을 때)
- 추천 문안에 유형이 최소 3가지 섞인다. 질문거리는 1개 이상
- 후보 전체에서 ChatGPT·Claude·Gemini 각각 최소 2건(공통 포함 계산 제외). 한 도구가 후보의 절반을 넘지 않는다
- 업무 관련도 「하」는 추천하지 않는다

반응 기록 반영
- 좋았던 유형·주제는 추천에 1건 더, 별로였던 유형은 1건 덜. 한 유형이 추천의 절반을 넘지 않는다
- 사용자가 실행 옵션으로 초점을 지정했으면(예: "팁 위주로", "Claude 소식만") 그 지정이 반응 기록보다 우선한다
- 어떻게 반영했는지 `feedback_applied`에 한 줄로 적는다

도구 분포와 유형 분포를 `distribution`에 숫자로 적는다.

## 6. 저장과 응답

`{실행 폴더}/02_curator_candidates.json`에 쓴다(형식은 `../ai-chat-curator/references/data-schema.md`). 응답은 "후보 N건(추천 K, 확인 필요 V), 제외 M건, 경로"만 짧게 한다.
