## 확인한 제약 (2026-11-23, developers.kakao.com)

- 나에게 보내기: `POST kapi.kakao.com/v2/api/talk/memo/default/send`, 동의항목 `talk_message`
- 텍스트 템플릿 `text` 최대 200자, `link` 필수, 링크 도메인은 앱에 등록한 웹 도메인만 허용
- 액세스 토큰 6시간(REST), 리프레시 토큰 2달·만료 1달 전부터 갱신 시 새 토큰 발급(기존 폐기)
- 클라우드 환경 네트워크 허용 목록에 kauth.kakao.com·kapi.kakao.com 필요
